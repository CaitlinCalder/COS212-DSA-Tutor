# Part 5 — App shell, skill tree, report and lecturer view

Part 5 owns the seven-step shell, student skill tree/report, lecturer demo heatmap, and Step 1 slides-to-video prototype. Parts 1–4 are consumed as dependencies and their source files are not modified.

## Slides-to-video demo
1. Drag PDF/PPT/PPTX lecture slides into the upload area (or browse).
2. Add the pre-generated NotebookLM MP4 using **Add NotebookLM MP4**.
3. Select **Generate video**. The UI simulates slide analysis and video preparation, then displays the supplied MP4 as output.

This is a prototype simulation. It does not call NotebookLM or generate a new video from the uploaded slides. The pre-generated MP4 must be supplied by the project team.
